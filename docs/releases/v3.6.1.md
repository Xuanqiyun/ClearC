## 3.6.1 更新：容量只写一次，行距更舒服
- **空间地图上，盘的容量只写一次**。原来 C 盘、D 盘的「已用 / 共多少」在下拉框、盘的卡片、下面的概览里各写一遍，有时还差 0.01 GB。现在下拉框只写盘符；卡片左边写「已用 / 共 · 百分比」，右边写「剩多少」；下面的概览只讲已用的空间里系统与软件、个人文件、可清理的缓存、其他各占多少，几类加起来正好是已用空间。在盘的最上一层，列表上面那行不再写和已用空间对不上的「这一层共多少」。各个页面的「已用、剩多少」按同一种算法读，同一块盘在哪里看都一样。
- **行距和字距**：会换行的文字按字号给约 1.5 倍行距，几行中文不再挤在一起；缩放 125% 以上的屏幕改用 Ideal 字形排列，字和字之间不再忽宽忽窄。

## 3.6 更新：更稳、更清楚
按三份评审（安全和运维、用户体验、架构）一条一条改的，每条都先写了测试。
- **删除更稳**：所有删用户文件的地方都走同一个入口，删前查个人文件夹、系统位置、链接和回收站放不放得下，删后核对、写操作日志；删重复文件也一个一个记下来。存密码、证书、密钥的文件夹，电脑上所有账户的都挡住。设置文件先写临时文件再替换，读不出来时一律不删。
- **同一时间只做一件事**：本工具只能开一个窗口；删除、搬家、改设置时，定时的自动清理碰上了就跳过这一次。
- **搬家中途断电也能收拾**：每做完一步记一次，下次打开说清停在哪一步，可以接着做完或撤回；复制完核对文件个数和大小，一个都不能差。搬走的聊天记录、桌面、文档带上原来的权限，电脑上的其他账户打不开，以前搬走的可以一键改过来。C 盘加了密而目标盘没有时，确认框里写明。
- **一键清理只删不搬**：聊天记录在清理页单独一张卡片，自己点才搬。只有 C 盘的电脑不会再整单失败；搬家目标不会自动选 USB 移动硬盘；有搬走的文件夹就显示「搬家管理」，链接断了会提醒。
- **第一次打开**：同意说明后自动扫描，结果一张卡片、一个主按钮。清理页的选项卡写着选了几项，可以「这一类全部跳过」，合计分删除和搬走；几个确认框合成一个，永久删除用红色。
- **看得清、用键盘也能用**：说明文字更深、最小 12 号字；键盘焦点有框，读屏软件读得出图标按钮；帮助只讲当前模式里有的功能。
- **少等、少猜**：输完管理员密码马上显示「正在打开」；帮助页第一次打开时才加载。换外观、换语言重开后回到原来的页面和扫描结果。出错时先说是什么情况、下一步怎么办。软件列表显示软件自己的图标。
- **其他**：C 盘快满、日志写不进去时会说；长时间操作期间电脑不睡着，用电池搬大文件夹先提醒；新加「设置 → 本工具改过的」，写着本工具改过的每项系统设置、现在的状态和怎么改回去，改系统设置前可以先建还原点；导出诊断包前列出里面有什么，可以不带内存转储；「自动提醒」显示任务上次、下次运行的时间和结果。

还没定的一件事：C 盘个人文件夹（桌面、文档、下载……）里的重复文件，现在仍然只能看、不能勾选删除。

## What's new in 3.6.1: sizes shown once, easier to read
- **Space map shows each drive's size once.** The drive picker shows only the letter; each drive card shows used / total / % and free space; the overview below only breaks the used space into system and apps, personal files, cleanable caches and other, adding up to the used space. Every page reads drive usage the same way, so a drive shows the same numbers everywhere.
- **Line and letter spacing**: wrapped text has about 1.5x line spacing, and on screens scaled 125% or more text uses ideal glyph spacing.

## What's new in 3.6: safer and clearer
Built item by item from three reviews (safety and operations, user experience, architecture), each with a test written first.
- **Safer deletes**: every user-file delete goes through one entry point that checks personal folders, system locations, links and Recycle Bin capacity, verifies the result and writes the activity log; duplicate deletes are logged one by one. Folders holding passwords, certificates and keys are blocked for every account on the PC. Settings are written atomically, and nothing is deleted if they cannot be read.
- **One thing at a time**: only one ClearC window runs, and scheduled cleanup skips its turn while a delete, move or settings change is in progress.
- **Moves survive a power cut**: every step is journaled, so the next start tells you where it stopped and lets you finish or undo it; the copy must match the original exactly (file count and size). Moved chat data, Desktop and Documents keep their permissions so other accounts can't open them, and earlier moves can be fixed in one click. You are warned when moving from an encrypted C: to an unencrypted drive.
- **One-click cleanup only deletes**: chat data has its own card and moves only when you click it. A PC with only C: no longer fails, USB drives are never picked as a move target automatically, Moved folders appears once something has been moved, and broken links are reported.
- **First run**: after you agree, it scans right away and shows one result card with one main button. Cleanup tabs show how many items are selected, a whole tab can be skipped, totals are split into delete and move, confirmations are merged into one, and permanent delete is red.
- **Easier to read and to use with a keyboard**: darker secondary text with a 12 pt minimum, a visible focus ring, names for icon buttons in screen readers, and help that only covers what the current mode shows.
- **Less waiting, less guessing**: a "starting" window appears right after the administrator prompt, Help loads on first use, a theme or language change returns to the same page and scan results, errors say what happened and what to do next, and apps show their own icons.
- **Also**: warnings when C: is nearly full or the log can't be written; no sleep during long jobs and a battery warning before big moves; a new Settings → What ClearC changed page listing every system setting ClearC changed, its state and how to undo it, with an optional restore point first; the diagnostics export lists its contents and can leave memory dumps out; reminder tasks show their last and next run.

Still open: duplicates inside C: personal folders (Desktop, Documents, Downloads…) can be viewed but not ticked for deletion.
